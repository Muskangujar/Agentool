# C++ HTML Schema Inference — Pattern Registry

## Architecture

`schema_infer.cpp` implements the central dispatcher. It parses the HTML with
libxml2, runs each registered platform detector in order, and calls the first
matching extractor. If no platform is detected, `extract_generic` scans the
document for `<code>VERB /path</code>` patterns.

```
infer_endpoints_json(url, html)
  └── infer_endpoints(url, html)
        ├── htmlReadMemory()        — libxml2 HTML parse
        ├── detect_mintlify(doc)?  → extract_mintlify
        ├── detect_readme(doc)?    → extract_readme
        ├── detect_swagger_ui(doc)? → extract_swagger_ui
        ├── detect_gitbook(doc)?   → extract_gitbook
        └── (fallback)             → extract_generic
```

## How to add a new pattern

1. Create `patterns/<platform>.cpp`.
2. Include `"schema_infer.h"`.
3. Implement:

```cpp
namespace agentool {

bool detect_myplatform(xmlDocPtr doc) {
    // Return true if this HTML was generated by <platform>.
    // Check for a unique generator meta tag, class prefix, or attribute.
}

void extract_myplatform(xmlDocPtr doc, std::vector<InferredFragment>& out) {
    // Fill `out` with InferredFragment entries.
    // If extraction yields nothing, call extract_generic(doc, out) as fallback.
}

} // namespace agentool
```

4. Declare the two functions in `schema_infer.h` (the detect/extract section).
5. Add `cpp/patterns/<platform>.cpp` to the `cxx_build::bridge(...)` call in
   `build.rs`.
6. Add a `{detect_myplatform, extract_myplatform}` entry to `k_handlers[]` in
   `schema_infer.cpp`.

## Detection signals per platform

| Platform    | Primary signals |
|-------------|-----------------|
| Mintlify    | `<script id="__NEXT_DATA__">`, class `mintlify-*` |
| ReadMe      | `<meta name="readme">`, `data-rdme` attributes |
| Swagger UI  | `<div id="swagger-ui">`, class `opblock` |
| GitBook     | `<meta content="GitBook">`, class `gitbook-*` |
| Generic     | `<code>VERB /path</code>` anywhere in document |

## libxml2 notes

- Use `HTML_PARSE_NOWARNING | HTML_PARSE_NOERROR | HTML_PARSE_RECOVER` when
  calling `htmlReadMemory` so malformed docs don't abort parsing.
- Always `xmlFree()` strings returned by `xmlNodeGetContent` and `xmlGetProp`.
- Always `xmlXPathFreeObject()` and `xmlXPathFreeContext()` after XPath use.
- The `xmlChar` type is `unsigned char*`; cast with
  `reinterpret_cast<const xmlChar*>(str)` and
  `reinterpret_cast<const char*>(xmlchar_ptr)`.
